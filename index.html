render2d

A map renderer in the spirit of the GDAL tools: data and a style in, a map out. Built on GDAL and Cairo, tested on the reference map of the Brussels Region.

Source on GitHub render2d notes viewer2d notes Features

What it does

  • Reads everything GDAL reads: shapefiles, GeoPackage, FlatGeobuf, GeoJSON, PostGIS tables, GeoTIFF and other rasters.
  • Styles in YSLD, GeoServer's YAML form of SLD: scale ranges, CQL filters, labels with halos, symbols, hatching, raster opacity; categorized and graduated classifications.
  • Writes PNG, SVG and PDF, with a report of every layer: features read and drawn, timings, warnings.
  • Answers questions: what is at this point, in this area, or matches this expression.
  • A command and a library: the same engine drives the command line, the web test bench, the tile generator and a desktop viewer.
render2d parcels.fgb --style parcels.yaml buildings.gpkg::Buildings --style buildings.yaml \
         --bbox 148000 168000 156000 175000 --size 1200 -o brussels.png

One style, every scale

The same three style files at three scales. Each rule says at which scales it applies: parcel boundaries and building outlines join in as one zooms in, then a dot per door, then the house numbers turned along the facades.

render2d data/UrbISBuildings_04000_CadastralParcels.shp --style styles/showcase/parcels.yaml \
         data/UrbISBuildings_04000_Buildings.shp      --style styles/showcase/buildings.yaml \
         data/UrbISBuildings_04000_Addresses.shp      --style styles/showcase/addresses.yaml \
         --bbox 140700 161000 158500 178700 --size 1600x1600 -o brussels-region.png

The styles: render2d/styles/showcase (YSLD). The other two images use the same command with another --bbox.

cd render2d/render2d
make fresh            # Windows: MSYS2 UCRT64 with GDAL, Cairo, yaml-cpp
